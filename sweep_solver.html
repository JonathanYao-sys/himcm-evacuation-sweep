派生量与校验
公式：边权 c_e = d_e / v_h；单间处理 s_i* = t_0 + α·a_i + β·n_i + t_rep + t_mark； 目标 T* = min max_r T_r，其中 T_r = Σ[dist(p_{k-1},p_k) + s*_{p_k}]。
页面算法与 src/sweep_core.js 一致，后者已逐项对齐 Python 版（16 组参数下结果完全相同）。 参数与《基础场景建模假设.md》第 2/3/4 节一一对应；v_room 是文档里的背景参数，不参与边权计算。
固定假设（文档第 4 节）：单层建筑不使用电梯；允许两名响应者并行搜索，故整楼完成时间取 max_r T_r； 响应者行走速度与走廊速度 v_h 相同。
